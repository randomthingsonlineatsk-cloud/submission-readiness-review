# Submission Readiness Review

A regulatory QC-review practice game.

**Live demo:** https://macaly-hjgyggc7g0j3t63td7jxzmcw-prod.macaly-app.com

> This is a fictional, educational demonstration. Do not use it for real patient data, clinical decisions or regulatory submissions.

## Features
- About 205 problems across Regulatory/CTD, Clinical Data Management, Pharmacovigilance, GCP and Post-Approval
- 21 regulators and 13 product categories
- Readiness score, weakest-domain breakdown, downloadable QC report
- Timed mode, flashcards, badges, shareable seeded challenges and a leaderboard

## Tech stack
TanStack Start, React, Tailwind CSS, Convex (leaderboard and sync). Built on Macaly Cloud.
